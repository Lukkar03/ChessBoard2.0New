Här är min version av ChessBoard2.0 
Programmet körs genom att användaren får mata in en siffra (3-50) som avgör hur stort schackbrädet ska vara
Programmet skriver sidan ut ett ett shackbräde i den storleken som användaren valt genom att loopa igenom varje rad och kolumn och lägger till en svart ruta för varje jämt tal och vit ruta för ojämt
